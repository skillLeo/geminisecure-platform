## For every later version

Write what the person holding the phone will notice, in their words, and nothing else: no build numbers, no
ticket numbers, no library names, and no list of features. If a release changes what is collected or asked
for, the first line says so (for example "The app now asks for the microphone, only when you tap it to
dictate a report."), and `PRIVACY_DECLARATIONS.md` and both consoles' privacy answers change in the same
release.
